spec for the symbol:
function$label = for label inside function (Foo.bar$loop)
function = for function symbol (Foo.bar)
function$ret.i = for each return addr after call command (Foo.bar$ret.1)

================================
if-goto:
*R14 = pop()
*R14+1;JEQ

function sequences:
--------------------------------
label functionname
for i in nlocal do push constant 0; pop local i; end

return sequences:
--------------------------------
endframe = LCL
retaddr = *(endframe - 5)
*ARG = pop()
*SP = *ARG + 1
*THAT = *(endframe - 1)
*THIS = *(endframe - 2)
*ARG = *(endframe - 3)
*LCL = *(endframe - 4)
goto retaddr

call sequences:
--------------------------------
push $ret
push *LCL
push *ARG
push *THIS
push *THAT
*ARG = *SP - 5 - nargs
*LCL = *SP
goto functionname
